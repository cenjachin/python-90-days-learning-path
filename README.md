逐日日程表：13 周每天学什么都排好了（如 D1 装环境、D22 with 语句、D64 起做项目），每天 2 小时拆成 40 分钟学 + 70 分钟练 + 10 分钟复盘
具体免费资源：廖雪峰教程、Kaggle Learn、CS50P、freeCodeCamp、Exercism 等，按阶段对应推荐
13 条避坑表：Tab/空格混用、只看不写、不用虚拟环境、中英文标点、乱码编码等，每条都配了正确做法
落后补救机制：缺 1–2 天周末补、缺 1 周把 W13 当缓冲周，核心原则“永远不要从 Day 1 重启”

💡 给你的三个关键建议

Day 1 装环境时，Windows 务必勾选 Add Python to PATH，能省掉很多麻烦
教程只选一个主资源跟着学，不要囤课——“收藏 ≠ 学会”
每天那 70 分钟练习比 40 分钟学习更重要，抄完代码一定要改参数再跑一遍
